# AI 助手与 WebMCP

## 配置模型

1. 点击顶栏的「AI 助手」，切到「配置」。
2. 添加支持 OpenAI 兼容接口的模型，填写接口地址、API Key 和模型名称。可以测试连接后再保存。
3. 将该模型设为当前模型，打开「对话」并输入任务。需要模型参考攻略全文或截图时，可以附上文本或图片。

## 在对话中使用工具

在「WebMCP」标签可以查看当前页面已注册的工具。对话中尽量写清游戏名、平台或其他识别信息。如果返回候选卡片，核对关联游戏和所选条目后再确认。

| 想完成的任务     | 可以这样描述                                             |
| ---------------- | -------------------------------------------------------- |
| 添加游戏         | 帮我搜索《游戏名》，显示候选后把我选中的版本加入游戏库。 |
| 补全角色或预告片 | 给库里的《游戏名》同步角色，或查找它的 Steam 预告片。    |
| 搜索和导入 OST   | 搜索《游戏名》的 OST，让我选择专辑和曲目后再导入。       |
| 导入攻略         | 把附件整理成 vnweb 攻略，关联到游戏库里的《游戏名》。    |
| 导出台词         | 按关键词或创建时间筛选摘录，并导出 XLSX。                |

游戏资料工具的数据取决于对应平台的配置。遇到账号权限或匹配问题时，可以先检查[平台接入与资料更新](./platforms)。
