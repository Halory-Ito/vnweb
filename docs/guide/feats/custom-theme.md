# 外观与主题

## 调整布局、字体与背景

在「设置 → 外观」可以调整以下项目。

- **布局**提供无边框等界面选项。
- **字体**可以选用本机字体并调整粗细，Windows 上可读取本机字体列表。
- **背景**可以启用自定义背景，按界面分组选择或上传图片，为明暗模式和移动端设置不同背景。

## 使用自定义主题

进入「设置 → 主题」，在 CSS 编辑区填写主题变量，保存后查看效果。可以从主题编辑器复制 shadcn/ui 格式的变量，使用 `:root` 定义浅色模式，使用 `.dark` 定义深色模式。要随源码维护一套默认样式，也可以编辑项目里的 `app/custom.css`。

- [tweakcn 主题编辑器](https://tweakcn.com/)
- [shadcn/ui 主题示例](https://ui.jln.dev/)
