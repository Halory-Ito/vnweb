# 扫描与游戏库

## 扫描本地游戏

1. 打开顶栏的「扫描」，点击「添加扫描目录列表」，选择游戏所在的上级目录。
2. 根据目录结构选择扫描模式。
   - **层级扫描**适合每款游戏各占一个目录的合集。例如游戏放在 `D:\Games\游戏名` 时，选择 `D:\Games`，层级填 `0`。如果中间多一层厂商目录，层级填 `1`。
   - **可执行文件扫描**按目录中的可执行文件查找游戏，适合目录层级不统一的情况。可以先在扫描配置中加入工具、卸载程序等所在的排除目录。
3. 保存后，点击对应扫描目录的开始按钮。要处理多个已登记目录，可以点击「扫描全部」。
4. 扫描结束后检查新增和失败结果，再到「游戏库」打开游戏详情，核对名称与可执行路径。

目录路径以运行 vnweb 的电脑为准。游戏移到另一块盘后，可在「游戏详情 → 设置 → 可执行路径」更新位置。

## 手动添加或批量导入

只添加一款游戏时，打开游戏库的添加菜单，选择「手动添加」。可以填写名称后搜索并选择资料，也可以直接填写基本信息。已有第三方收藏时，使用同一菜单下的「从第三方导入」。[平台接入与资料更新](./platforms)

## 整理游戏库

- 在游戏库切换文件夹、列表、网格或混合布局，配合筛选和排序查找游戏。
- 用收藏夹组织正在玩、待通关或同系列的游戏。需要处理多款游戏时，进入多选模式，选中条目后使用批量菜单。
- 点击游戏进入详情页。在「概览」核对资料，在「设置」配置启动和存档路径。「相关人物」「PV」「OST」「记录」「回忆」「摘录」「攻略」展示该游戏关联的内容。

设置好可执行路径后，可以[启动游戏并记录时长](./play-records)。
