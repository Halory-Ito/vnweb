# 角色、摘录与回忆

## 整理角色资料

打开「游戏详情 → 相关人物」。需要补录时，打开「角色同步设置」，选择数据来源，核对或填写该平台的游戏 ID，再点击「保存」开始同步。也可以勾选「将角色图片保存到本地」。点击角色进入详情，可以查看关联的台词。

## 添加和导出台词

1. 从顶栏进入「摘录」，或打开游戏详情中的「摘录」标签。
2. 点击「添加摘录」，填写台词并关联游戏。有角色资料时，也可以指定角色，方便从角色页回看。
3. 用搜索和筛选查找条目。要导出时，在全局「摘录」页点击「导出 XLSX」，选择包含的游戏和导出方式。

## 写游玩回忆

打开「游戏详情 → 回忆」新建条目，上传截图并填写标题和正文，再按需关联 OST 配乐。正文可以使用 Markdown，例如用二级标题划分章节，用引用块记下印象深刻的对话。保存后点开条目阅读。

- 在「设置 → 回忆」维护自定义元数据字段，例如游玩平台或个人评分。
- 在同一页设置回忆配乐的播放行为。要在回忆中选曲，先在 [OST](./media) 中整理相关歌曲。
