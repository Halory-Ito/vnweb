# PV 与 OST

顶栏的「PV」和「OST」用于浏览整个游戏库的媒体。游戏详情中的同名标签只显示当前游戏关联的条目。

## 添加与播放 PV

1. 在「PV」打开新增表单，选择所属游戏并填写 PV 名称。
2. 粘贴视频链接，或开启「上传本地视频」选择文件。链接可使用支持的 Bilibili、YouTube、视频直链或 HLS 地址。
3. 保存后点击条目播放。站内无法播放时，可从播放器打开原始链接。

## 导入与播放 OST

1. 打开「OST」，点击「添加 OST」并选择关联游戏。
2. 选择「专辑关键词搜索」查找网易云音乐专辑，或用「专辑 ID」读取已知专辑。核对版本后保存待添加的专辑。
3. 手动整理音轨时，进入专辑详情，在「添加歌曲」中填写歌名和音频地址。可以指定 `.lrc` 歌词文件路径，或直接粘贴歌词文本。
4. 点击曲目开始播放。全局播放器支持切换播放模式、查看队列和展开全屏歌词。

读取专辑或播放失败时，在「设置 → 平台」核对 Meting SDK 或 Enhanced API 的配置，再检查音频链接是否还能访问。
