# 平台接入与资料更新

## 配置平台

打开「设置 → 平台」，启用需要使用的平台，再按界面填写凭证。查询公开资料、读取个人收藏和推送游玩状态使用的权限可能不同，个人功能需要先绑定账号。

| 平台        | 配置方式与用途                                                                                                                    |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Steam       | 配置 Steam Web API Key，绑定 Steam 账号后可导入拥有的游戏，并在账号卡片中使用「同步游戏时长」。读取库存需要账号公开相关游戏资料。 |
| Bangumi     | 按页面提示填写个人访问令牌。使用镜像时一并核对所选接口来源。绑定后可读取收藏并推送状态。                                          |
| VNDB        | 使用 VNDB 令牌绑定账号。根据所需操作授予读取列表或修改列表的权限。                                                                |
| YMGal       | 配置 Client ID 和 Client Secret 查询月幕资料。需要读取账号收藏时，按页面提示绑定用户 ID。                                         |
| SteamGridDB | 配置 API Key 后，可用于补充封面、背景、图标和徽标等图片。                                                                         |

## 导入收藏与更新资料

1. 要把平台收藏加入本地库，打开「游戏库 → 添加菜单 → 从第三方导入」，选择来源并勾选要导入的游戏。
2. 要给已有条目补资料，在游戏详情的右键菜单中选择「更新资料数据」，按游戏名或平台 ID 查找对应条目。核对版本和名称，再应用搜索结果。
3. 要单独维护图片、匹配平台条目或修改可执行路径，打开游戏详情的「设置」。第三方条目导入后，如需启动本地安装的游戏，在这里核对可执行路径。

## 同步游玩状态

在「设置 → 平台」为 Bangumi 或 VNDB 绑定账号，检查本地状态与平台状态的映射。在游戏详情编辑游玩状态，通过对应的平台入口选择或确认条目后保存。Steam 的时长同步从「设置 → 平台」的 Steam 账号卡片发起。
