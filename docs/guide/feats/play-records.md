# 启动与游玩记录

## 启动游戏并计时

1. 在「游戏库」打开一款游戏，进入「设置」，确认「可执行路径」指向要运行的程序。
2. 回到详情页点击「开始游戏」。vnweb 会启动本地程序并监控游玩进程。
3. 正常退出游戏后，在该游戏的「记录」标签查看这次游玩。需要从 vnweb 结束游戏时，使用详情页的「结束游戏」。

游戏经由启动器打开时，如果时长与预期不符，先核对「可执行路径」是否指向实际游玩的进程。也可以用[命令行工具](./other)启动最近一次游玩的游戏。

## 查看主页与统计

- **主页**显示近期游玩、连续天数、总时长和已通关数量。点击目标编辑入口，可以设置每日游玩时长和本年度通关数量目标。
- **记录 → 总览**用来回顾游玩趋势、活动热力图和时长分布。需要查看单月或整年的数据时，切换到「月报」或「年报」。
- **记录 → 数据**用来检查游玩明细。只想核对某款游戏时，直接进入该游戏详情的「记录」。

## 导出年度报告

打开「记录 → 导出报告」，选定年份、模板、游戏数量和要展示的信息，然后点击「生成海报」下载 PNG。
