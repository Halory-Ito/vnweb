# 备份、恢复与同步

相关操作都在「设置 → 备份」。游戏存档备份会复制指定游戏的存档，应用备份和远程同步则按选中的类别保存 vnweb 数据。

## 自动备份游戏存档

1. 在「游戏存档」区开启「启用游戏存档备份」，选择备份文件的存放目录并保存。
2. 打开要备份的「游戏详情 → 设置」，将「存档路径」指向游戏实际写入存档的目录，例如游戏目录下的 `UserData`。
3. 通过 vnweb 启动一次游戏并正常退出，在备份目录确认已经生成该游戏的备份。

如果担心游戏所在磁盘损坏，可以将备份目录放到另一块磁盘。

## 本地备份与恢复

1. 在「备份内容」检查要包含的数据类别。
2. 在「本地备份」点击「立即备份」。要将备份保存到其他地方，可使用「导出 ZIP」。需要表格数据时，可使用「导出 XLSX」。
3. 恢复已有本地备份时，在列表中选择对应条目的「恢复」。迁移已有 ZIP 时，使用「导入备份」并选择该压缩包。

::: warning 恢复会替换当前数据
恢复或导入前，先核对备份日期和数据类别。需要保留当前数据时，先另存一份 ZIP。
:::

## 通过 WebDAV 或 S3 同步

1. 在「同步服务器」添加 WebDAV 或 S3 配置，按界面填写服务器地址及凭证，并设置备份目录或存储桶。
2. 上传前先打开备份统计，核对选中的类别和文件大小，再确认上传。
3. 在另一台设备配置同一个同步位置，打开下载预览，核对远端备份日期与内容后再确认拉取。

拉取会先备份即将被覆盖的本地文件，再用远端数据替换对应内容。目标设备关闭游戏存档备份时，拉取会跳过游戏存档。
