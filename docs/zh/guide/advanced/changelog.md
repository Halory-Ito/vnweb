## 已落地能力明细

### 文档与开源

- 为文档首页导航和功能分组使用 SVG 图标，统一 VitePress 首页与正文的视觉风格和响应式布局。
- 编写分模块的 VitePress 使用指南并更新文档导航；英语为主站根路径 `/`，简体中文位于 `/zh/`。
- 添加 AGPL-3.0 开源许可并更新授权声明。

### OST 与音乐

- OST 专辑关键词搜索统一直连网易云音乐网页接口；结果面板限制宽度并防止表格溢出。
- 搜索结果支持分页，默认每页 10 张，并保留跨页选择；按选中的网易云专辑 ID 导入。
- 兼容仅支持单曲读取的 Meting 服务；支持配置 Enhanced API 的 `MUSIC_U` 并在播放时传给服务端。
- 展示区标注 Enhanced 或 Meting 来源；统一平台设置与外观设置的组件尺寸和字号。

### 设置与平台

- 平台配置调用统一迁至 `data/settings/platform.json`，移除旧配置入口；SQLite 路径集中到 `data/settings/general.json`。
- 初始化时从示例补齐缺失文件；串行保存平台配置并原子替换文件，避免并发覆盖。
- 校验平台配置字段类型与端口范围；显示平台读取错误及重试入口，保留无法读取的配置文件。
- 为 VNDB、Bangumi、YMGal、Steam 添加官方凭据获取入口与用途提示面板。
- Bangumi 改用个人令牌绑定，移除 OAuth；令牌获取地址支持镜像配置。
- Steam OpenID 登录绑定入口及回调验证；VNDB Token 写入权限检查。
- 外观中设置多对一状态映射并同步到 Bangumi / VNDB；切换状态立即保存，支持按平台手动同步并显示进度。
- 持久化每款游戏的平台推送记录，自定义四种推送状态的指示点颜色；平台显示开关按用途分组并持久化。
- 平台设置优先读取浏览器缓存，缓存缺失时读服务端。

### 攻略、回忆与媒体

- 优化攻略工具栏响应式布局，进入攻略详情页时切换对应游戏背景。
- 优化攻略卡片比例与容器响应式列数，底部分页支持按行数与每行列数配置。
- 修复路线分支拖拽排序失效；进度条按进度分段着色，100% 时提供明显完成反馈。
- 重构游戏详情页攻略标签页，消除嵌套滚动与卡片套娃，接入自定义颜色、防误触确认与独立入口。
- 回忆支持解析 Markdown frontmatter；新增/编辑表单统一为限宽限高的可滚动弹窗，支持描述、标签、日期与自定义元数据。
- 回忆图片 alt 自动作为图注；回忆关联 OST 曲目与进入详情页自动播放。
- 设置 → 回忆支持自定义元数据与图标搜索；回忆批量删除。
- OST 唱片架按屏幕宽度设置默认每层数量；悬浮播放器待播队列支持展开/收起动画。

### 备份与同步

- 重构备份设置页样式与组件结构：平级卡片流、outlined 按钮、AlertDialog 确认、Skeleton 加载态。
- 上传前统计面板展示数据库、存档、图片等类别的文件数、大小与占比。
- 备份内容支持自定义：游戏存档、11 类图片、视频、音频、字体；品牌图标作为独立图片分类。
- 远端上传先打包 `backup.zip`，生成 `backup-meta.json` 日期文件；下载支持压缩包拉取解压并兼容旧版未压缩备份，带实时进度条。
- 所有设置文件（含 `custom.css`）纳入本地备份、ZIP 导入导出与远端同步。
- Tauri 桌面端的备份 ZIP、XLSX 与报告 PNG 导出使用原生另存为窗口。

### 打包与桌面端

- 通过 `lib/server/runtime-paths.mjs` 收口应用目录与用户数据目录，解耦 `process.cwd()` 路径读写。
- 服务端启动与 CLI 启动自动补齐配置并执行数据库迁移，兼容存量 `local.db` 接管与新库创建。
- Next.js 配置 `output: 'standalone'` 与产物裁剪；新增 `build-cli.mjs`、`build-standalone.mjs`。
- 建立 Cargo Workspace 与 `crates/vnweb-cli` 原生 CLI 入口；无参拉起桌面端，带参转发 CLI，默认共享 `%APPDATA%\vnweb`。
- 搭建 Tauri v2 桌面壳：单实例锁、系统托盘、Windows Job Object 子进程托管、端口分配与就绪探活、外部链接调起系统浏览器。
- 资源预置脚本内嵌 `node.exe`、standalone 与 `vnweb.exe`；NSIS 安装/卸载钩子维护 `PATH`。
- GitHub Actions 在推送 `main` 后构建 Windows x64 安装包并发布 Release，自动生成描述与标题。
- 设置中新增「关于」标签，展示项目资料并检查 GitHub 更新。
- 默认开启无边框、混合布局、按开发商分类、自定义背景、毛玻璃 4px / 80%。
- 新增「开启原生标题栏」设置并联动 Tauri 窗口装饰。
- 启动动画支持图片/视频模式、独立配置、时长与跳过设置；双击画面或 Esc 跳过。
- 桌面端首次初始化与启动加载界面采用项目浅/深色阶与衬线品牌美学，并带步骤进度反馈。

## 更新日志维护规范

新增版本记录时建议遵循以下约定：

1. **版本标题**：使用真实发布版本号与日期，例如 `## [0.2.2] - 2026-xx-xx`。不要为未发布改动编造版本号。
2. **分类**：采用 `Added` / `Changed` / `Fixed` / `Removed` / `Security` 五类；中文文档可使用「新增 / 变更 / 修复 / 移除 / 安全」。
3. **条目粒度**：一条改动写一件事，说明用户可见影响，避免"优化体验"这类空话。
4. **关联**：能对应到 Issue / PR 的附上链接；对应 `plan.md` 条目的同步打勾。
5. **破坏性变更**：数据库 schema、配置字段或 CLI 参数变化时，单独标注迁移步骤。
6. **修复错误**：按仓库习惯优先查看 `errors.md`，修复后把对应条目从该文件删除。
7. **多语言**：中英文文档保持同一版本脉络；英文站内链接使用 `/` 根路径，中文站内链接统一使用 `/zh/` 绝对路径。

示例模板（仅示意，不代表已发布版本）：

```md
## [示例 0.x.0] - 2026-xx-xx

### 新增

- 新增 CG 画廊，支持按游戏与分类浏览 CG。

### 修复

- 修复某些窄屏下攻略工具栏溢出的问题。

### 安全

- 模型请求的发送范围现在会在配置页明确提示。
```
