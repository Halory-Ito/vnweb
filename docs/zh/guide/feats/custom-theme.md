# 外观与主题

vnweb 的外观系统分为三个层次：**布局与交互**（侧栏、边框、标题栏、卡片）、**字体与背景**（全局字体、壁纸、毛玻璃）和**主题变量**（shadcn/ui 风格的 CSS 变量）。所有设置保存在 `data/settings/appearance.json`，示例模板位于 `data/example/appearance.json`；自定义主题写在 `custom.css` 中，两者都会随备份一起保存。

> 改动外观前建议先了解项目统一的[设计规范](/zh/guide/advanced/contributing#代码规范)，它规定了字号阶梯、响应式截断与组件约束。

## 设置项总览

| 分组              | 关键项                                                    | 默认值                             |
| ----------------- | --------------------------------------------------------- | ---------------------------------- |
| `layout`          | 侧栏/顶栏隐藏、无边框、原生标题栏、游戏库布局、分组与圆角 | 无边框开启、混合布局、按开发商分组 |
| `font`            | 字体文件、字号、字重                                      | 16px / 400                         |
| `background`      | 自定义背景（PC / 移动端）、切换动效                       | 开启，center-fade，420ms           |
| `glass`           | 毛玻璃模糊与透明度                                        | blur 4px / opacity 80%             |
| `chart` / `guide` | 图表主色、攻略步骤类型颜色                                | 图表 `#e84479`                     |
| `status`          | 游玩状态名称与指示点颜色                                  | 四种推送状态可自定义               |
| `emptyState`      | 空状态颜文字或图片                                        | `(´・ω・\`)`                       |
| `startup`         | 启动动画（图片/视频、时长、跳过方式）                     | 默认关闭                           |

## 调整布局、字体与背景

进入「设置 → 外观」即可调整以下项目。

### 布局与边框

- **侧栏 / 顶栏隐藏**：按需收起全局导航元素，给内容区更多空间。
- **无边框（borderless）**：控制组件边框的表现。应用内组件的边框需要参考这个开关的状态，开启时整体更简洁。默认开启。
- **原生标题栏（nativeTitleBar）**：仅在 Tauri 桌面端生效。关闭原生标题栏后，全局 Header 支持拖动、双击最大化，右侧显示自定义的最小化 / 最大化（还原）/ 关闭按钮。
- **游戏库布局**：提供文件夹、列表、网格、混合四种；可设置网格展示方式、按开发商分类、卡片标题显隐与圆角。
- **文件夹色板**：支持循环与随机取色，操作按钮右对齐。

::: tip 打包版与源码版的差异
原生标题栏相关设置只影响桌面端窗口装饰；在浏览器里运行时由浏览器自身控制窗口。
:::

### 字体

- 可以选用本机字体。Windows 上会读取系统字体列表。
- 可调整**全局字号**与**字重**，保存后需要用户确认应用才生效。
- 全局字体统一由 CSS 变量 `--app-font-family` 驱动：

  ```css
  :root {
    --app-font-family: '你的字体', serif;
  }
  ```

::: warning 不要在组件里指定字体族
项目规范要求组件中不要通过 `font-mono` / `font-sans` / `font-serif` 等类区分字体，统一使用 `--app-font-family`。例外：路径、域名、编号与代码按设计规范可使用 `font-mono`；字体预览区也可展示实际字体。
:::

### 背景与毛玻璃

- 启用自定义背景后，可以为**明暗模式和移动端**分别选择或上传图片。
- 切换动效支持 `center-fade` 等样式，并可调整持续时间（默认 420ms）。
- 毛玻璃参数 `glass.blur`（默认 4px）与 `glass.opacity`（默认 80%）控制界面叠加层的模糊与透明度。
- 背景与外观的同步触发做了渲染隔离，切换设置标签时不会出现边框闪帧。

### 启动动画（桌面端）

「外观 → 启动动画」支持图片与视频两种模式，各自保留独立配置与文件：

| 配置项                 | 说明                         |
| ---------------------- | ---------------------------- |
| `enabled`              | 是否启用启动动画             |
| `activeType`           | `image` 或 `video`           |
| `durationMs`           | 图片展示时长（默认 2000ms）  |
| `skippable`            | 是否允许跳过                 |
| `muted`                | 视频是否静音播放             |
| `matchMediaWindowSize` | 按素材分辨率安全缩放启动窗口 |

跳过方式是**双击画面或按 Esc**，界面上没有跳过按钮。图片和视频都支持在上传前或上传后重命名，并会完整铺满启动窗口。

## 使用自定义主题

进入「设置 → 主题」，在 CSS 编辑区填写主题变量，保存后即可看到效果。格式沿用 shadcn/ui 约定：

```css
:root {
  --background: oklch(0.99 0 0);
  --foreground: oklch(0.2 0 0);
  --primary: oklch(0.55 0.2 280);
  --primary-foreground: oklch(0.98 0 0);
  --border: oklch(0.9 0 0);
  --radius: 0.5rem;
}

.dark {
  --background: oklch(0.16 0 0);
  --foreground: oklch(0.95 0 0);
  /* 深色模式变量 */
}
```

- `:root` 定义浅色模式，`.dark` 定义深色模式。
- 主题编辑器可以复制 shadcn/ui 格式的变量。
- 要随源码维护一套默认样式，可以编辑项目的 `app/custom.css`。当应用目录与数据目录分离时（例如 Tauri 打包版），运行时读取的是数据目录下的 `custom.css`，源码中的文件不会直接影响已安装的应用。

推荐工具：

- [tweakcn 主题编辑器](https://tweakcn.com/)
- [shadcn/ui 主题示例](https://ui.jln.dev/)

::: danger 自定义 CSS 的风险
主题编辑区接受任意 CSS，错误的规则可能让界面不可读。建议先备份 `custom.css`（它会随[备份](/zh/guide/feats/save-backup)一起保存）。如果改坏了，从备份恢复该文件即可。
:::

## 设计规范速查

新增或修改页面时，需要遵循 `DESIGN.md` 的约定：

| 场景       | 规范                                                                   |
| ---------- | ---------------------------------------------------------------------- |
| 页面标题   | 常规页面不重复渲染顶层 `<h1>`，由导航激活态与浏览器标签页承担定位      |
| 区块标题   | `text-lg sm:text-xl font-semibold tracking-tight`                      |
| 正文       | `text-sm leading-relaxed`                                              |
| 辅助信息   | `text-xs text-muted-foreground`                                        |
| 数字       | 排行榜、百分比、时长等必须加 `tabular-nums`                            |
| 长文本截断 | 父容器 `min-w-0`，文本用 `truncate` / `line-clamp-2`，避免固定像素宽度 |
| 组件       | 优先 shadcn/ui 已有组件，优先 outlined 风格，避免卡片套卡片            |
| 响应式     | 每次改动都要检查窄屏布局与样式一致性                                   |

单个组件文件不超过 200 行；超过 150 行考虑拆分子组件，业务逻辑用自定义 hook 抽离。

## 排错

| 现象                       | 处理方式                                                    |
| -------------------------- | ----------------------------------------------------------- |
| 字体修改后没有变化         | 确认已在确认弹窗中应用，并等待设置写盘                      |
| 自定义背景在手机上不显示   | 移动端背景是独立配置项，需单独上传                          |
| 主题变量保存后部分颜色没变 | 检查是否只写了 `:root` 而漏了 `.dark`，或变量拼写错误       |
| 边框开关似乎无效           | 刷新页面确认；部分组件边框由无边框开关统一控制              |
| 桌面端看不到自定义窗口按钮 | 仅在关闭「原生标题栏」后出现                                |
| 启动动画没有播放           | 检查 `enabled` 与媒体文件是否已上传；视频模式下确认文件存在 |
| 页面在窄屏下溢出           | 检查是否缺少 `min-w-0` 或固定宽度硬截断                     |
