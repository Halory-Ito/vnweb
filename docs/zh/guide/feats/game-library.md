# 扫描与游戏库

游戏库是所有功能的主入口：扫描把本地目录变成条目，资料刮削让它变得可读，启动与记录围绕它展开，PV、OST、攻略、回忆也都挂在它下面。第一次建库建议跟着[快速开始](/zh/guide/intro/quick-start)走一遍。

## 扫描本地游戏

### 登记扫描目录

1. 打开顶栏的「扫描」，点击「添加扫描目录列表」，选择游戏所在的上级目录。
2. 根据目录结构选择扫描模式（见下表）。
3. 保存后，点击对应扫描目录的开始按钮。要处理多个已登记目录，可以点击「扫描全部」。
4. 扫描结束后检查新增和失败结果，再到「游戏库」打开游戏详情，核对名称与可执行路径。

::: tip 路径以本机为准
目录路径以运行 vnweb 的电脑为准。即使从另一台机器访问 Web 界面，扫描读到的仍是服务端所在电脑的磁盘。
:::

### 两种扫描模式

| 模式               | 适用场景                              | 层级怎么填                           | 例子                                                                           |
| ------------------ | ------------------------------------- | ------------------------------------ | ------------------------------------------------------------------------------ |
| **层级扫描**       | 每款游戏各占一个目录的合集            | 游戏目录与上级目录之间隔几层，就填几 | `D:\Games\游戏名` → 选 `D:\Games`，层级 `0`；`D:\Games\厂商\游戏名` → 层级 `1` |
| **可执行文件扫描** | 目录层级不统一，或想直接按 exe 找游戏 | 不需要层级                           | 在混杂目录中找出所有可执行文件对应的游戏                                       |

层级必须是**大于等于 0 的整数**；填错时保存会被拒绝。

### 排除路径

扫描配置里可以维护一份全局排除路径列表。把工具、卸载程序、运行环境等目录加进去，避免它们被误识别为游戏。

```text
D:\Games\_tools
D:\Games\CommonRedist
D:\Games\__MacOSX
```

::: warning 排除路径是字符串匹配
如果你发现某款游戏始终扫不出来，先检查它的上级路径是否被排除规则误伤；反之如果扫出一堆噪音，先补充排除路径再重扫。
:::

### 识别规则与实际结果

扫描做的是「发现候选」，不是「保证准确」：

- 层级扫描以上级目录下的子目录为候选，层级决定往里走几层。
- 可执行文件扫描以目录中的可执行文件为线索。
- 扫描结果仍需要你到游戏库里核对名称、封面和可执行路径；必要时用手动添加或平台导入修正。

### 目录搬家之后

游戏移到另一块盘后，可在「游戏详情 → 设置 → 可执行路径」更新位置。命令行启动尤其依赖绝对路径，详见[启动与游玩记录](./play-records#启动游戏并计时)。

## 手动添加或批量导入

### 手动添加一款

只添加一款游戏时，打开游戏库的添加菜单，选择「手动添加」。可以填写名称后搜索并选择资料，也可以直接填写基本信息。

适合这些情况：

- 扫描结果名称不对，想重新建一条。
- 游戏不在常规目录里，比如单文件版或绿色版。
- 你已经知道要绑定哪个平台条目，想直接从搜索结果建库。

### 从第三方导入

已有第三方收藏时，使用同一菜单下的「从第三方导入」。选择来源（如 Steam、Bangumi、VNDB、YMGal），加载账号收藏后勾选要导入的游戏。

```text
游戏库 → 添加菜单 → 从第三方导入 → 选择来源 → 勾选条目 → 确认导入
```

::: tip 先配凭证再导入
个人收藏属于需要账号授权的数据，先在[平台接入与资料更新](./platforms#配置平台)绑定账号，再回来导入。导入后如果要在本地启动，还要在详情「设置」里核对可执行路径。
:::

导入来源与配置字段见[平台接入与资料更新](./platforms)；导入后的资料更新策略见同页的[导入收藏与更新资料](./platforms#导入收藏与更新资料)。

## 整理游戏库

### 四种布局

在游戏库可以切换**文件夹、列表、网格、混合**四种布局：

| 布局   | 适合场景                             |
| ------ | ------------------------------------ |
| 文件夹 | 按目录/分组浏览，接近资源管理器习惯  |
| 列表   | 一屏看更多条目，便于按名称、时长比对 |
| 网格   | 以封面为主，视觉浏览                 |
| 混合   | 左侧分类 + 右侧内容，适合大型库      |

默认外观设置通常会开启无边框与混合布局；布局属于外观偏好，可在[外观与主题](./custom-theme)里调整。

### 筛选与排序

配合筛选和排序快速定位游戏。常见维度包括名称、游玩时长、最近运行、评分、平台/开发商分类与收藏夹。

::: tip 大型库的组织方式
先用「按开发商分类」或收藏夹把库切成小块，再在块内按最近游玩排序。这样比每次全库搜索更快。
:::

### 收藏夹与批量操作

- 用收藏夹组织正在玩、待通关或同系列的游戏。
- 需要处理多款游戏时，进入多选模式，选中条目后使用批量菜单。
- 已有条目重复时，可以使用合并流程整理；合并前请确认两边的数据与记录，避免丢失会话。

::: danger 批量操作先确认范围
批量更新或删除会同时影响多条记录。执行前先核对筛选条件与选中数量，尤其是带自定义封面、回忆或攻略的条目。
:::

### 游戏详情页

点击游戏进入详情页。常用区域：

| 区域               | 作用                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------- |
| 概览               | 简介、基本信息（开发商/发行商/发售日/类型/引擎/平台）、标签与附加信息                    |
| 设置               | 可执行路径、存档路径、图片与平台关联                                                     |
| 相关人物           | 角色与立绘，见[角色、摘录与回忆](./game-notes)                                           |
| PV                 | 关联预告片，见[PV 与 OST](./media#添加与播放-pv)                                         |
| OST                | 关联专辑与曲目，见[PV 与 OST](./media#导入与播放-ost)                                    |
| 记录               | 这款游戏的时长曲线，见[启动与游玩记录](./play-records)                                   |
| 回忆 / 摘录 / 攻略 | 玩家自己沉淀的内容，见[角色、摘录与回忆](./game-notes)与[攻略与路线进度](./walkthroughs) |

## 封面与元数据

### 资料从哪里来

扫描只负责建条目；封面、简介、标签、角色、发行商等元数据主要靠平台补全：

1. 在「设置 → 平台」启用相关平台并填写凭证。
2. 在游戏详情的右键菜单中选择「更新资料数据」，按游戏名或平台 ID 查找对应条目。
3. 核对版本和名称，再应用搜索结果。

图片类资料（封面、背景、图标、徽标）也可以通过 SteamGridDB 等来源补充，字段与用途见[平台接入与资料更新](./platforms#配置平台)。

### 手动维护

要单独维护图片、匹配平台条目或修改可执行路径，打开游戏详情的「设置」。第三方条目导入后，如需启动本地安装的游戏，一定要在这里核对可执行路径。

::: warning 名称与版本
同一作品可能有原版、重制版、汉化版多个条目。更新资料时以「发售日、开发商、平台」交叉核对，避免把重制版封面贴到原版上。
:::

## 常见问题

### 扫描结果为 0

1. 确认选的是上级目录而不是游戏目录本身。
2. 确认层级填对：`D:\Games\游戏名` 填 `0`，再多一层厂商目录填 `1`。
3. 检查排除路径是否覆盖目标目录。
4. 目录层级混乱时换「可执行文件扫描」。

### 扫出来一堆不是游戏的东西

把工具、卸载程序、运行环境目录加入排除路径，然后重扫。必要时删除误建条目再重新扫描。

### 游戏名不对或封面错乱

用「更新资料数据」按平台 ID 重新匹配；名称可以直接在基本信息里修正。匹配时留意版本差异。

### 导入后无法启动

第三方收藏只带来资料，不带来本地可执行文件。到游戏详情「设置」填写本机绝对路径，参见[启动与游玩记录](./play-records#启动游戏并计时)。

### 条目重复

在批量操作中使用合并流程；合并前确认两边的记录与媒体关联，必要时先做一次[备份](../feats/save-backup)。

### 图片显示失败

平台图片接口可能受网络影响。先确认平台配置可用，再尝试重新更新资料；详见[平台接入 → 速率限制与失败处理](./platforms#速率限制与失败处理)。

## 小结

- 扫描负责「发现」，人工核对负责「准确」。
- 层级扫描看目录结构，可执行文件扫描看 exe。
- 平台导入能快速建库，但本地启动仍需可执行路径。
- 四种布局 + 收藏夹 + 批量操作，是管理大型库的关键。
