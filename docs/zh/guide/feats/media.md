# PV 与 OST

顶栏的「PV」和「OST」用于浏览整个游戏库的媒体。游戏详情中的同名标签只显示当前游戏关联的条目。两者都是「挂在游戏上的内容」：先有[游戏库](./game-library)里的条目，再把视频和音乐挂上去。

## 添加与播放 PV

1. 在「PV」打开新增表单，选择所属游戏并填写 PV 名称。
2. 粘贴视频链接，或开启「上传本地视频」选择文件。链接可使用支持的 Bilibili、YouTube、视频直链或 HLS 地址。
3. 保存后点击条目播放。站内无法播放时，可从播放器打开原始链接。

### 支持的地址类型

| 来源         | 例子                                 | 播放方式                |
| ------------ | ------------------------------------ | ----------------------- |
| Bilibili     | 视频页链接、分享短链、播放器嵌入链接 | 解析为嵌入播放器        |
| YouTube      | `watch?v=...`、`shorts/...`          | 解析为嵌入播放器        |
| 视频直链     | 以 `.mp4`、`.webm` 结尾的地址        | 直接播放                |
| HLS / 流地址 | 以 `.m3u8`、`.mpd`、`.ism` 等结尾    | 由播放器按流媒体处理    |
| 本地文件     | 开启「上传本地视频」后选择文件       | 上传后由 vnweb 提供访问 |

Bilibili 分享短链会先经过短链解析，再转成可嵌入的地址；因此粘贴时既可以用完整视频页链接，也可以用常见的分享链接。

::: tip 选哪种方式

- 公开视频优先用链接，省空间，也能跟随源站更新。
- 源站可能下架或需要登录时，用「上传本地视频」更稳。
- 想把预告片当背景循环播放时，HLS 或直链通常更顺畅。
  :::

### 元数据与整理

PV 条目可以填写名称与补充说明等元数据，并按所属游戏归类。媒体标题建议写清楚语言与版本，例如「PV1 中文配音版」「OP 完整版」，避免同一作品的多条视频混淆。

在全局「PV」页按游戏筛选；在游戏详情的「PV」标签只看当前游戏。需要删除时进入对应管理入口确认。

### 播放失败怎么办

1. 先点「打开原始链接」，确认视频在源站本身可播。
2. Bilibili / YouTube 嵌入失败时，检查浏览器是否限制了第三方嵌入。
3. 直链失败时检查地址是否过期、是否需要鉴权或防盗链。
4. 本地上传后仍失败时，确认文件没有被移动或清理，见[记录 → 数据](./play-records#关于「记录-→-数据」)中的本地资源说明。
5. 在公司/校园网络里，视频域名可能被网关拦截，换网络再试。

## 导入与播放 OST

1. 打开「OST」，点击「添加 OST」并选择关联游戏。
2. 选择「专辑关键词搜索」查找网易云音乐专辑，或用「专辑 ID」读取已知专辑。核对版本后保存待添加的专辑。
3. 手动整理音轨时，进入专辑详情，在「添加歌曲」中填写歌名和音频地址。可以指定 `.lrc` 歌词文件路径，或直接粘贴歌词文本。
4. 点击曲目开始播放。全局播放器支持切换播放模式、查看队列和展开全屏歌词。

### 专辑来源

| 来源         | 怎么导入                             | 适合场景                             |
| ------------ | ------------------------------------ | ------------------------------------ |
| 网易云音乐   | 按专辑关键词搜索，或输入已知专辑 ID  | 中文圈 OST、同人音乐、常用来源       |
| Meting SDK   | 通过平台设置里的 SDK 配置读取        | 需要与网易云接口解耦、自定义播放码率 |
| Enhanced API | 配置 `apiBase`、`musicU`、音质与端口 | 需要更高音质或本地 SDK 调用方式      |
| khinsider    | 按专辑/原声集条目读取                | 日文原声、游戏原版 CD                |

搜索结果会标注来源（例如 Enhanced 或 Meting），方便你知道这条专辑是通过哪条链路读到的。

### 专辑 ID 与关键词搜索怎么选

- 记得专辑名但不确定 ID：用**关键词搜索**，结果支持分页，选中后可以跨页保留选择。
- 已经有了准确 ID：直接用**专辑 ID 读取**，最快也最不容易选错。
- 同名专辑很多：用 ID，或核对封面、年份、曲目数后再保存。

::: warning 版本核对
同一部作品常有原声集、arrange 版、广播剧 CD 等多个发行。保存前核对封面与曲目列表，避免把不同版本混进一个专辑。
:::

### 音轨与元数据

进入专辑详情后可以整理曲目：

- 歌名、音频地址、时长与封面。
- 歌词：指定 `.lrc` 文件路径，或直接粘贴歌词文本。
- 来源信息：来自网易云、Meting 或 khinsider 的曲目会带有各自的标识。

手动添加一首歌的典型信息：

```text
歌名：       Colorful World
音频地址：   https://example.com/audio/track01.mp3
歌词：       /path/to/track01.lrc   （或粘贴文本）
```

::: tip 歌词文件
`.lrc` 文件里的时间轴标签决定逐字/逐句高亮。没有歌词文件时，直接粘贴歌词文本也能显示，但不会有精确的时间同步。
:::

## 播放与整理

### 全局播放器

点击曲目后会出现播放器，支持：

| 能力     | 说明                                   |
| -------- | -------------------------------------- |
| 播放模式 | 顺序播放、列表循环、单曲循环、随机播放 |
| 队列     | 查看待播列表，可展开/收起              |
| 全屏歌词 | 展开全屏模式，显示实时高亮歌词         |
| 可视化   | 多种专辑主题舞台，随播放呈现动态效果   |
| 悬浮卡片 | 切换到其他页面后仍可控制播放           |

```text
顺序播放 → 列表循环 → 单曲循环 → 随机播放 → （回到顺序播放）
```

### 整理专辑

- OST 唱片架按屏幕宽度设置默认每层数量：宽屏通常 2 层、每层 10 张；窄屏通常 2 层、每层 5 张。
- 在游戏详情的「OST」标签里，只展示这款游戏关联的专辑；单专辑时可以自动展开。
- 支持批量删除；删除前确认封面、曲目与歌词是否还需要。
- 专辑详情可进入独立页管理，便于集中编辑曲目信息。

## 常见问题

### 搜不到专辑

1. 在「设置 → 平台」核对 Meting 或 Enhanced API 配置。
2. 关键词尽量用专辑原名或发行方，避免只用作品中文名。
3. 换用已知专辑 ID 直接读取。

### 专辑读取失败

- 确认网络能访问对应音乐服务。
- Enhanced API 场景下检查 `apiBase`、`musicU`、`quality` 与本地 SDK 端口；见[平台接入与资料更新](./platforms#ost-相关-meting-与-enhanced-api)。
- Meting 场景下检查码率与封面尺寸配置；部分服务只支持单曲读取，导入策略可能不同。

### 能导入但不能播放

多半是音频直链失效、需要鉴权，或源站有防盗链。先打开音频地址确认可访问，再换一条来源。平台接口的问题见[平台接入 → 速率限制与失败处理](./platforms#速率限制与失败处理)。

### 歌词不同步

检查 `.lrc` 文件的时间轴；从网页复制的歌词常常只有纯文本，没有时间标签。可以先粘贴文本应急，再补一份规范 LRC。

### PV 在站内播不了

先打开原始链接验证源站；嵌入被限制时改用直链或本地上传。详见[播放失败怎么办](#播放失败怎么办)。

### 媒体文件被清理了

「记录 → 数据」可以清理未被数据库和配置引用的本地文件。执行前请确认没有仍被引用的上传文件；详见[游玩记录 → 关于记录 → 数据](./play-records#关于「记录-→-数据」)。

## 小结

- PV 支持 Bilibili、YouTube、直链、HLS 与本地上传；站内播不了就打开原始链接。
- OST 可从网易云、Meting、Enhanced API 与 khinsider 导入，也支持手动填曲目和 LRC 歌词。
- 全局播放器提供四种播放模式、队列、全屏歌词与可视化舞台。
- 搜索/播放失败优先核对平台设置与音频链接。
