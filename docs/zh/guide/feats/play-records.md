# 启动与游玩记录

vnweb 不只帮你打开游戏，还会把每次游玩变成可回顾的数据。这一篇讲清楚计时是怎么发生的、数据存到哪里、怎么按月/按年看，以及怎么导出成海报。前置操作（建库、设置路径）见[游戏库](./game-library)与[快速开始](/zh/guide/intro/quick-start)。

## 启动游戏并计时

1. 在「游戏库」打开一款游戏，进入「设置」，确认「可执行路径」指向要运行的程序。
2. 回到详情页点击「开始游戏」。vnweb 会启动本地程序并监控游玩进程。
3. 正常退出游戏后，在该游戏的「记录」标签查看这次游玩。需要从 vnweb 结束游戏时，使用详情页的「结束游戏」。

![游戏详情页展示，显示游玩时长与最近运行时间](/overview.png)

### 计时是怎么发生的

一次游玩在数据库里大致对应一条会话记录：

| 字段                   | 含义                 |
| ---------------------- | -------------------- |
| 关联游戏               | 这条会话属于哪款游戏 |
| 开始时间 `startAt`     | 会话起点             |
| 时长 `durationSeconds` | 本次游玩秒数         |
| 运行状态 `isRunning`   | 是否仍在计时         |
| 可执行路径             | 本次实际启动的程序   |

「开始游戏」时会启动程序、写入开始时间并标记运行中；会话结束时计算时长并落库。因此它统计的是**从启动到结束的这一段时间**，而不是游戏内部的存档时间。

::: warning 经由启动器打开时
如果时长与预期不符，先核对「可执行路径」是否指向实际游玩的进程。路径指向启动器、外壳程序或另一个 exe，都可能导致计时对象不对。修正方法见[游戏库 → 整理游戏库](./game-library#整理游戏库)。
:::

### 命令行启动与计时

也可以用[命令行工具](./other)启动游戏并计时：

```bat
vnweb start 12       :: 启动 ID 为 12 的游戏
vnweb start          :: 快速启动最近一次游玩的游戏
```

命令行版本会实时显示 `本次计时: HH:MM:SS`，按 `q` 结束并保存会话，`Ctrl+C` 则直接退出。

## 会话记录怎么看

- **单款游戏**：打开详情的「记录」标签，可以按**周 / 月 / 年**切换区间，并在折线图与柱状图之间切换。
- **全局回顾**：打开「记录」页面，从总览、月报、年报里看整体节奏。
- **按天/按周**：月报里的「每日游戏时长统计」给出当月的逐日曲线；单款游戏的「记录」切到「周」可以看到这一周的逐日分布。

::: tip 时间边界
按周查看时，区间按自然周（周日起）计算；按月/按年则按自然月、自然年。向前翻页用左右箭头，不能翻到未来。
:::

## 查看主页与统计

### 主页速览

主页显示近期游玩、连续天数、总时长和已通关数量，并支持设置目标：

| 指标        | 说明                                     |
| ----------- | ---------------------------------------- |
| 近 7 天游玩 | 最近一周的累计时长                       |
| 连续游玩    | 当前连续游玩天数；今天还没玩时从昨天算起 |
| 游戏总时长  | 所有落库会话的累计时长                   |
| 已通关      | 标记为已完成的数量                       |

点击目标编辑入口，可以设置**每日游玩时长（分钟）**和**本年度通关数量**，主页会用进度环显示完成情况。目标保存在 `data/settings/general.json` 的 `goals` 字段。

### 记录 → 总览

总览用来回顾整体规模与分布：

| 卡片/图表                  | 读法                                                         |
| -------------------------- | ------------------------------------------------------------ |
| 游戏总数、时长、天数、次数 | 单次会话数不等于天数，同一天多次游玩只算一个活跃日           |
| 角色 / OST / PV / 台词数量 | 反映内容沉淀的丰富程度                                       |
| 单次游玩时长分布           | 按时长区间统计会话次数，看自己是「短平快」还是「一口气推完」 |
| 游戏时间分布               | 按小时段统计总时长，并标出高峰时段                           |
| 游戏时间排行 / 评分排行    | 找出真正花时间的项目                                         |

::: tip 图表颜色
统计图的颜色与透明度沿用[外观与主题](./custom-theme)里的图表设置，所以换主题时统计页也会跟着变。
:::

### 月报

月报适合看「这个月发生了什么」：

- 区间游戏时长、活跃天数、峰值时段。
- 每日游戏时长统计（折线/柱状），可切到具体某一天。
- 本月游戏频率，按游玩次数统计前 10。
- 本月游戏时长排名。

### 年报

年报适合看「这一年我的叙事生活」：

- 月度游戏时长、月度游戏天数（折线/柱状）。
- 年度游戏时间分布：可按**游戏类型**或**发行商**切换的饼图。
- 年度游戏排名。

### 周报与日报的位置

当前「记录」导航默认列出 **总览、年报、月报、导出报告、数据** 几项。代码里保留了周度视图，但默认导航未必列出；想看周/日的颗粒度，可以这样读：

- **按周**：打开单款游戏的「记录」，切到「周」。
- **按日**：打开「月报」的每日曲线，或在单款游戏「记录」的周视图里看逐日柱子。

### 关于「记录 → 数据」

::: warning 不要找错页面
「记录 → 数据」显示的是**本地静态资源数据**（图片、字体等本地文件的占用统计与未使用资源清理），不是游玩明细。要核对某次会话，请到单款游戏的「记录」或总览/月报。
:::

## 数据导出

### 年度报告海报

打开「记录 → 导出报告」，选定年份、模板、游戏数量和要展示的信息，然后点击「生成海报」下载 PNG。

| 可选项   | 说明                                           |
| -------- | ---------------------------------------------- |
| 年份     | 选择要回顾的年度，也可查看全部                 |
| 模板     | 经典、现代、极简、游戏四种风格                 |
| 游戏数量 | 控制海报上显示多少款作品                       |
| 展示信息 | 游戏时长、评分、最后游玩时间、游玩次数、封面等 |
| 颜色     | 背景色与标题色                                 |

桌面端导出时会走原生另存为窗口，方便直接指定保存位置。

### 其他导出

- 台词摘录支持按关键词或创建时间筛选并导出 XLSX，见[角色、摘录与回忆](./game-notes)。
- 计时记录也支持 XLSX 导出，桌面端同样使用原生另存为窗口。
- 备份 ZIP 的导出与导入见[备份、恢复与同步](./save-backup)。

## 可视化图表一览

| 图表            | 出现在哪里               | 用途                      |
| --------------- | ------------------------ | ------------------------- |
| 折线图 / 柱状图 | 单款游戏记录、月报、年报 | 展示时间序列的时长变化    |
| 饼图            | 年报                     | 按类型/发行商拆分时长占比 |
| 热力图          | 主页/总览相关区域        | 以日历形式展示活跃强度    |
| 排行卡片        | 总览、月报、年报         | 按时长或评分排序          |
| 进度环          | 主页                     | 每日与年度目标完成情况    |

图表数据来自落库的会话，因此**先有完整记录，再有好看的图**。如果图表空着，先确认游戏是否真的启动并结束过会话。

## 常见问题

### 玩了但时长是 0

1. 会话是否已正常结束？中途强关 vnweb 可能来不及落库。
2. 「结束游戏」是否被误点？提前结束会截断时长。
3. 可执行路径是否指向实际游玩进程？

### 时长比实际多很多

游戏已经关闭但进程仍在后台驻留时，vnweb 可能仍在计时。确认退出方式，必要时用详情页的「结束游戏」。

### 连续天数断了

连续天数按自然日计算，今天还没玩时从昨天起算。补记历史会话不在常规操作范围内，建议如实记录。

### 统计和单游戏记录对不上

检查筛选条件与时间区间：全局统计与单款游戏记录的区间边界、NSFW 条目显示等口径可能不同。以同一页面内的数据为准。

### 目标设了没变化

目标按配置保存并在主页读取。修改后刷新页面；配置位于 `data/settings/general.json`，服务端读取需要重启时请重启应用。

### 海报生成失败

确认年份有数据、封面资源可访问；网络图片失败时可先更新资料，详见[平台接入 → 失败处理](./platforms#速率限制与失败处理)。

## 小结

- 计时基于「启动 → 结束」的会话，关键是可执行路径正确。
- 单款游戏看「记录」的周/月/年；全局看总览、月报、年报。
- 「记录 → 数据」是本地资源清理，不是游玩明细。
- 年报可以导出四种风格的 PNG 海报，桌面端支持原生另存为。
