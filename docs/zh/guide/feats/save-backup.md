# 备份、恢复与同步

vnweb 把这组能力拆成两类：

- **游戏存档备份**：复制各游戏真实写入磁盘的存档目录，由 vnweb 在游戏退出时自动触发。
- **应用数据备份 / 同步**：保存 vnweb 自己的数据库、设置文件和本地资源，支持本地备份、ZIP 导入导出、WebDAV 与 S3 兼容对象存储同步。

相关入口主要在「设置 → 备份」，同步服务器配置也在「设置 → 同步」。两类数据互不替代：即使开启了远程同步，也建议单独开启游戏存档备份。

> 开始之前请完成[安装与配置](/zh/guide/intro/installation-and-configuration)并添加游戏，见[扫描与游戏库](/zh/guide/feats/game-library)。

## 备份内容清单

应用数据备份按类别选择，默认勾选数据库、设置文件、游戏存档和全部图片类，视频、音频、字体默认不勾选。

| 类别              | 默认 | 说明                                               |
| ----------------- | ---- | -------------------------------------------------- |
| 数据库            | 必含 | `local.db`（或 `general.json` 中指定的数据库文件） |
| 设置文件          | 必含 | `data/settings/*` 与 `custom.css`                  |
| 游戏存档          | 开启 | 各游戏 `saveDir` 指向的目录                        |
| 图片 · 游戏封面   | 开启 | `cover`                                            |
| 图片 · OST 封面   | 开启 | `ost`                                              |
| 图片 · 游戏背景   | 开启 | `bg`                                               |
| 图片 · 自定义背景 | 开启 | `bg/custom`                                        |
| 图片 · 角色立绘   | 开启 | `characters`                                       |
| 图片 · 游戏 CG    | 开启 | `cg`                                               |
| 图片 · 游戏图标   | 开启 | `icon`                                             |
| 图片 · 游戏 Logo  | 开启 | `logo`                                             |
| 图片 · 品牌图标   | 开启 | 文件夹 Logo（`brands`，兼容旧目录）                |
| 图片 · 回忆图片   | 开启 | `memory`                                           |
| 图片 · 其他图片   | 开启 | 未归类的图片                                       |
| 视频              | 关闭 | `pv` 下的 `.ogg` 等                                |
| 音频              | 关闭 | OST 音频与 `.lrc` 歌词                             |
| 字体              | 关闭 | 本地字体文件                                       |

图片共 11 个细分分类，设置页默认展开。分类可以在备份设置、上传前统计面板、本地备份、ZIP 导出/导入和远端同步中统一控制。

## 自动备份游戏存档

1. 在「设置 → 备份 → 游戏存档」区开启「启用游戏存档备份」，选择备份文件的存放目录并保存。
2. 打开要备份的「游戏详情 → 设置」，将「存档路径」指向游戏实际写入存档的目录，例如游戏目录下的 `UserData`。该路径保存在 `game_info.saveDir`。
3. 通过 vnweb [启动游戏](/zh/guide/feats/play-records)并正常退出，在备份目录确认已经生成该游戏的备份。

::: tip 目录选择建议
如果担心游戏所在磁盘损坏，把备份目录放到另一块物理磁盘。桌面端可通过原生目录选择窗口指定可执行文件与存档目录。
:::

## 本地备份与恢复

### 立即备份

1. 在「备份内容」核对要包含的类别。
2. 在「本地备份」点击「立即备份」。
3. 要将备份保存到其他位置，使用「导出 ZIP」；需要可编辑的表格数据时，使用「导出 XLSX」。

每个备份条目前会显示日期，便于找回对应时间点的状态。

### 恢复与导入

1. 在备份列表中选择对应条目，点击「恢复」。
2. 迁移已有的 ZIP 文件时，使用「导入备份」并选择压缩包。
3. 恢复完成后重新打开应用，检查游戏库、攻略与设置是否符合预期。

::: danger 恢复会替换当前数据
恢复或导入不是合并，而是用备份内容替换当前数据。操作前先核对备份日期和数据类别；需要保留当前数据时，先另存一份 ZIP。
:::

实现上，资源目录恢复会先把将被覆盖的文件复制到 `${目录}.bak`，再写入备份中的文件；设置文件恢复同样会生成 `data/settings.bak`。此外，设置文件名有白名单校验：拒绝 `.`、`..`、含路径分隔符、以 `.` 开头以及 `.bak` / `.tmp` 结尾的名称，避免压缩包写入意外路径。

## 通过 WebDAV 或 S3 同步

### 添加同步服务器

在「同步服务器」添加配置，按界面填写：

| 协议            | 字段                                                                                             |
| --------------- | ------------------------------------------------------------------------------------------------ |
| WebDAV          | `server`、`username`、`password`、`remotePath`                                                   |
| S3 兼容对象存储 | `endpoint`、`bucket`、`region`、`accessKeyId`、`secretAccessKey`、`forcePathStyle`、`remotePath` |

`remotePath` 默认为 `/vnweb-backup`。同一套 `SyncClient` 接口屏蔽了两种协议的差异，提供连接测试、目录列举、上传/下载文件与目录、进度回调等能力。

### 上传

1. 在「同步服务器」确认配置已启用且连接测试通过。
2. 打开**上传前统计面板**，核对选中的类别、文件数、大小与占比。面板不会列出具体文件名，避免敏感路径泄露在截图中。
3. 确认后上传。远端会先打包成 `backup.zip`，再生成 `backup-meta.json` 日期文件。
4. 上传过程显示进度条与百分比，按类别展示进度，不逐文件刷屏。

::: warning 先确保数据库可用
上传前统计会检查数据库文件是否存在。如果数据库缺失或路径异常，面板会给出阻断原因，此时不能上传。
:::

### 下载与冲突处理

1. 在另一台设备配置同一个同步位置。
2. 打开下载预览，界面会检测远端备份日期并展示统计确认面板。
3. 核对内容后确认拉取。下载支持压缩包解压恢复，并兼容旧版未压缩备份，过程中显示实时下载进度条。

冲突处理规则：

- 拉取前先把即将被覆盖的本地文件备份为 `.bak`，再替换为远端内容。
- 数据库是整体替换，不会逐条合并。两端都修改过数据时，**后拉取的一方会覆盖自己的本地数据**。
- 目标设备如果关闭了游戏存档备份，拉取会跳过游戏存档类别。
- 多设备使用建议：固定一台主设备上传，其他设备只拉取；拉取前先在本地另存 ZIP。

## 安全与加密提示

::: danger 凭证与隐私
同步配置中的账号密码、S3 Access Key 属于敏感信息，保存在本地配置中。不要把包含这些字段的截图或配置文件公开。
:::

- vnweb 本身不对备份包做端到端加密。传输安全取决于你的 WebDAV / S3 服务是否启用 TLS；对象存储可开启服务端加密（SSE）。
- 如果备份中包含游戏存档、台词摘录或回忆正文，建议使用加密的远程存储或加密容器。
- 远程路径尽量使用专用目录，不要与其他应用共用根目录。
- 恢复来自他人的 ZIP 前，先确认来源可信；恢复逻辑对设置文件名做了白名单，但数据库内容本身无法校验来源。

## 排错

| 现象                           | 处理方式                                                     |
| ------------------------------ | ------------------------------------------------------------ |
| 游戏退出后没有生成存档备份     | 检查总开关、备份目录权限、该游戏的 `saveDir` 是否正确        |
| 统计面板提示"数据库文件不存在" | 检查 `data/settings/general.json` 的 `dbFileName` 与实际文件 |
| WebDAV 连接测试失败            | 核对服务器地址、账号密码与远程目录权限                       |
| S3 上传报 403                  | 检查 Access Key、bucket、region 与 `forcePathStyle` 设置     |
| 上传进度条卡住                 | 检查网络与对象存储限流；大备份可先精简图片分类               |
| 下载后提示格式不兼容           | 确认远端是 `backup.zip` 或旧版未压缩备份；重新上传一次       |
| 恢复后设置丢失                 | 检查是否勾选了设置文件；查看 `data/settings.bak`             |
| 两端数据互相覆盖               | 按"单一主设备上传"策略重新同步，拉取前先导出 ZIP             |
