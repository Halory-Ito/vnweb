# 快速开始：5 分钟从零到玩

这篇文档把[安装与配置](./installation-and-configuration)之后的所有必要动作串成一条路径：**启动 → 扫描 → 补资料 → 设置路径 → 启动游戏 → 查看记录 → 备份**。每一步都给出最短操作；细节和排错链接到对应的功能文档。

::: tip 前置条件
已经按[安装与配置](./installation-and-configuration)跑起 vnweb，并能打开 Web 界面。如果还没装，先回到那篇；如果想知道 vnweb 能做什么，先看[什么是 vnweb](./what-is-vnweb)。
:::

## 全程一览

| 步骤 | 目标     | 预计动作                      | 详细文档                                               |
| ---- | -------- | ----------------------------- | ------------------------------------------------------ |
| 0    | 启动服务 | 运行 `vnweb` 或 `npm run dev` | [安装与配置](./installation-and-configuration)         |
| 1    | 建库     | 登记目录并扫描                | [扫描与游戏库](../feats/game-library)                  |
| 2    | 补资料   | 配置至少一个平台并更新数据    | [平台接入](../feats/platforms)                         |
| 3    | 能启动   | 设置可执行路径                | [游戏库 → 整理](../feats/game-library#整理游戏库)      |
| 4    | 留下记录 | 开始游戏、正常退出            | [启动与游玩记录](../feats/play-records)                |
| 5    | 看到统计 | 打开记录总览                  | [启动与游玩记录](../feats/play-records#查看主页与统计) |
| 6    | 保住成果 | 做一次本地备份                | [备份、恢复与同步](../feats/save-backup)               |

## 第 0 步：启动服务

如果你用的是 Windows 一键初始化，新开一个终端：

```bat
vnweb
```

然后浏览器打开 `http://localhost:8999`。

如果你用的是源码手动安装：

```bash
npm run dev      # http://localhost:3000
# 或
npm run build && npm run start   # http://localhost:8999
```

<!-- 截图位：浏览器中的 vnweb 主页仪表盘，显示近 7 天游玩、连续天数、总时长与通关数 -->

::: warning 打不开页面
先确认服务是否仍在运行、端口是否正确。生产模式默认 8999 且监听 `0.0.0.0`，开发模式默认 3000。端口冲突的处理见[安装与配置 → 常见安装故障](./installation-and-configuration#常见安装故障)。
:::

## 第 1 步：扫描本地游戏

假设你的游戏这样放：

```text
D:\Games\
  ├─ 素晴日\
  │    └─ SUMMER.exe
  ├─ 魔法使之夜\
  │    └─ Mahoutsukai.exe
  └─ 弹丸论破1\
       └─ Danganronpa.exe
```

1. 打开顶栏「扫描」。
2. 点击「添加扫描目录列表」，选择上级目录 `D:\Games`。
3. 因为每款游戏各占一个目录，选择**层级扫描**，层级填 `0`。如果中间还多一层厂商目录，层级填 `1`。
4. 如果有工具、卸载程序等不想被识别，先在扫描配置里加入排除路径。
5. 保存后点击对应目录的开始按钮；登记了多个目录时可以「扫描全部」。
6. 检查新增与失败结果，再到「游戏库」打开游戏详情，核对名称和可执行路径。

<!-- 截图位：扫描页，显示已登记的目录、扫描模式选择、排除路径与扫描结果 -->

目录层级不统一时改用**可执行文件扫描**。扫描规则的细节见[扫描与游戏库](../feats/game-library#扫描本地游戏)。

## 第 2 步：补齐封面与资料

扫描通常只能带来目录名和路径。想看到封面、简介、开发商、角色，需要接平台：

1. 打开「设置 → 平台」，启用需要的平台并填写凭证。第一次上手建议至少配置 **SteamGridDB API Key**（补图片）和你最常用的一两个资料源。
2. 回到游戏库，打开一款游戏的详情，使用「更新资料数据」按游戏名或平台 ID 搜索对应条目。
3. 核对版本与名称后应用结果；图片不理想时，再到详情的「设置」里单独调整。

![游戏详情页展示，显示封面、简介、基本信息与标签](/game-preview.webp)

::: tip 不必一次配齐
平台凭证可以按需逐步配置。查询公开资料、读取个人收藏、推送游玩状态使用的权限可能不同；个人功能才需要先绑定账号。字段说明见[平台接入与资料更新](../feats/platforms#配置平台)。
:::

## 第 3 步：设置可执行路径

1. 打开游戏详情，进入「设置」。
2. 核对「可执行路径」是否指向你实际要运行的程序，例如 `D:\Games\素晴日\SUMMER.exe`。
3. 若游戏经由启动器打开，但时长与预期不符，优先检查这里是否指向了真正游玩的进程。

::: danger 路径必须是本机绝对路径
命令行启动时要求可执行文件为本机绝对路径，且文件存在。游戏搬到另一块盘后一定要回来更新。详见[游戏库 → 整理游戏库](../feats/game-library#整理游戏库)。
:::

## 第 4 步：启动游戏并计时

回到详情页点击「开始游戏」。vnweb 会启动本地程序并监控游玩进程。正常退出游戏后，本次会话会落库；需要从 vnweb 主动结束时，使用详情页的「结束游戏」。

```bat
rem 也可以用命令行启动指定游戏
vnweb start 12

rem 不带参数则快速启动最近一次游玩的游戏
vnweb start
```

命令行版本会显示实时计时，按 `q` 结束并保存。更多命令见[命令行工具](../feats/other)。

## 第 5 步：查看记录

1. 打开某款游戏的「记录」标签，按周 / 月 / 年切换，查看这款游戏的时长曲线。
2. 打开全局「记录」页面，先看「总览」：游戏总数、时长、天数、次数，以及单次时长分布、时段分布、时间排行与评分排行。
3. 想看更细的节奏，切换到「月报」（每日时长、游戏频率）或「年报」（月度时长、活跃月份、类型/发行商分布、年度排名）。
4. 需要一键生成年度回顾时，打开「导出报告」，选年份、模板、游戏数量与要展示的信息，下载 PNG 海报。

<!-- 截图位：记录总览页，显示统计卡片与时长分布图表 -->

统计维度与图表说明见[启动与游玩记录](../feats/play-records#查看主页与统计)。

## 第 6 步：做一次备份

最后别忘了一件事：把成果保住。

1. 打开「设置 → 备份」。
2. 先做一次**本地备份**，确认数据库、设置文件与本地资源都被纳入。
3. 如果需要在多台设备之间同步，再按[备份、恢复与同步](../feats/save-backup)配置 WebDAV 或 S3。

::: warning 备份前
确认没有正在运行的游戏会话和写库操作；`init.bat` 之类会重建数据库的操作更要先另存备份。
:::

## 命令行加速版

如果你已经熟悉命令，整条路径可以压缩成这样：

```bash
# 1. 启动服务（另一个终端保持运行）
vnweb

# 2. 查看库里已有游戏，确认 ID
vnweb list game

# 3. 搜索目标游戏
vnweb search 素晴日

# 4. 启动并计时（按 q 结束保存）
vnweb start 12

# 5. 不带参数，快速续玩最近一次的游戏
vnweb start
```

扫描、平台配置和备份仍建议在 Web UI 中完成；命令行的完整列表见[命令行工具](../feats/other)。

## 常见卡点

| 现象            | 先检查什么                                                                             |
| --------------- | -------------------------------------------------------------------------------------- |
| 扫描不到游戏    | 层级是否填对、是否选错上级目录、排除路径是否误伤                                       |
| 搜不到资料      | 平台是否启用、凭证是否有效、游戏名是否需要手动指定平台 ID                              |
| 启动报错        | 可执行路径是否绝对且存在，是否被启动器包了一层                                         |
| 时长为 0 或异常 | 是否指向了实际游玩进程，是否提前结束了会话                                             |
| 统计页没数据    | 是否已有落库会话，刷新页面重试                                                         |
| 图片显示失败    | 平台图片接口是否可用，详见[平台接入 → 失败处理](../feats/platforms#速率限制与失败处理) |

更多问题见[常见问题](/zh/guide/advanced/faq)与[术语表](/zh/guide/advanced/glossary)。
