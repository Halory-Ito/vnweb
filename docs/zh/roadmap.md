# 公开路线图

**面向数字文化的开源、本地优先、Agent 原生基础设施。**

vnweb 从视觉小说与本地单机游戏出发，把分散的社区元数据接入用户自己的本地资料库，并探索 AI Agent 如何在明确的人类控制下处理、连接与理解叙事内容。

::: info 定位与说明
本页基于仓库根目录的 [ROADMAP.md](https://github.com/Halory-Ito/vnweb/blob/main/ROADMAP.md) 编写，明确区分 `v0.2.2` **已交付能力**、**规划中功能**与**拟议 AI 研发方向**。研究条目用于说明实验目标与预期开源产出，范围和推进顺序取决于原型评估结果，不代表具体版本的发布承诺。
:::

## 项目愿景

大多数游戏管理工具只把作品视作“封面 + 启动按钮”。但数字文化——尤其是视觉小说——背后有着丰富的叙事结构：路线分支、结局、角色关系、原声配乐、台词摘录与个人游玩轨迹。

vnweb 的长期目标是让作品、角色与叙事素材能够**跨来源关联、检索与复用**，同时把控制权交给用户：由你决定哪些数据永远留在本地，哪些可以提交给外部服务处理。

## 规划中的游戏库功能

公开路线图中近期规划的资料库扩展能力：

- **CG 画廊**（`规划中`）：为每款游戏提供专门的 CG 浏览、分类与管理模块。

## 拟议 AI 研发方向

以下方向描述探索性原型实验与研究里程碑：

### 1. 多模态叙事理解

`拟议研发`

探索从**用户主动选择**的文本片段与游戏截图中抽取角色、关键事件与路线关系。核心评估指标为抽取质量与**可溯源性**——回答是否能准确回溯至原始文本或画面依据。

### 2. 语义知识图谱

`拟议研发`

为**作品、角色、路线与叙事事件**定义可复用的开放 Schema，跨社区元数据与本地笔记保留来源出处（provenance），并支持图谱查询与可移植导出。

### 3. 剧透感知 GraphRAG

`拟议研发`

基于玩家**当前所在路线与游玩进度**进行知识图谱检索。评估维度包括：

- 不同游玩进度下的**剧透泄漏率（Spoiler Leakage）**
- 针对剧情、角色与选项问题的**检索相关性**
- 生成答案在来源片段上的**事实落地程度（Grounding）**

### 4. Agent 工作流与生成式 UI

`拟议研发`

扩展现有 [WebMCP](/zh/guide/feats/ai-assistant) 工作流，提供更完整的结构化工具结果、变更前后预览以及写入资料库前的显式确认门槛，并评估工具选择准确率与任务完成率。

### 5. 开源交付与评估基准

`预期产出`

在具备 OpenAI API 等推理、嵌入、结构化输出与工具调用实验条件时，计划向社区回馈以下开源成果：

- 可复用的 Schema、抽取与检索组件
- 文档化的参考实现
- 基于合成语料或合规授权材料构建的可复现评估基准

## 隐私、权限与安全目标

当 Agent 工作流同时接触本地私人库与第三方导入的攻略/元数据时，安全边界是不可妥协的设计前提：

| 方向                     | 目标设计                                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------------------- |
| **本地默认与外发可见性** | 个人资料库与游玩进度默认留在本地；每次向外部模型发起请求时，数据范围与目标地址对用户清晰可见。 |
| **工具权限与读写分离**   | 明确划分只读检索与状态写入权限，关键修改必须经过用户显式确认。                                 |
| **提示词注入抗性评估**   | 评估 Agent 在消费导入元数据、第三方攻略与外部文本时对提示词注入攻击的抵御能力。                |
| **凭据与供应链审查**     | 随着外部集成扩展，持续审查凭据存储、本地数据保护与依赖供应链风险。                             |
